SOUND SPHERE — OFFLINE PROJECT

1. Extract the entire ZIP file.
2. Open the SoundSphere folder.
3. Open index.html in Chrome, Edge, or Firefox.
4. Select Start Exploring. Your browser may require a click before audio can play.

The project runs locally and includes its main scripts, styles, images, fonts, Three.js library, and NASA GISTEMP data. Keep the folder structure intact.

LANGUAGE
English is the default language. Use the language button in the header to switch to Arabic and back.

NASA EARTH MAPS
Open maps.html or select Earth Maps from the navigation. The interactive map uses NASA GIBS imagery and requires an internet connection. Available layers: MODIS Terra land-surface temperature, MODIS active-fire thermal anomalies, GHRSST MUR sea-surface temperature, and MODIS Terra sea ice. NASA ASCAT ocean-wind data is linked as a verified source, but is not yet rendered as a map layer.

PROJECT CONTENT
- NASA GISTEMP v4 annual global temperature anomaly data, 1880–2025 (included snapshot; not live data).
- NASA Scientific Visualization Studio climate spiral image sonification experiment.
- The advanced lab generates tones in the browser from the selected data or image. These are data sonifications, not natural recordings of Earth.

SOURCES
NASA GISS GISTEMP: https://data.giss.nasa.gov/gistemp/
NASA SVS climate spiral: https://svs.gsfc.nasa.gov/5190/

This is an independent educational prototype inspired by The Earth Information Jukebox challenge. It is not produced by, endorsed by, or affiliated with NASA.

NOTE
The supplied project contains the temperature dataset and climate-spiral image experiment. It does not include NASA wind or wildfire datasets/audio, so those are not represented as completed features in this build.
